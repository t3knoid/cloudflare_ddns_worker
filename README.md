# TP-Link Omada to Cloudflare DDNS Proxy Worker

A secure, lightweight Cloudflare Worker script that allows **TP-Link Omada routers** to update Cloudflare DNS records dynamically. 

Because Cloudflare's API does not natively accept standard dynamic DNS HTTP GET requests generated by consumer and enterprise routers, this Worker acts as an authenticated translator between your Omada hardware and the Cloudflare API.

## Features

- **Zero Secrets in Code:** Fully compliant with security best practices using Cloudflare Environment Variables.
- **Cost Efficient:** Minimizes Cloudflare API consumption by comparing current DNS records and skipping unnecessary updates if your IP has not changed.
- **Secure:** Validates an arbitrary secret token provided by your router before talking to Cloudflare.

## 1. Cloudflare Configuration

### Step 1: Create a Cloudflare API Token
1. Log in to your Cloudflare Dashboard and go to **My Profile** > **API Tokens**.
2. Click **Create Token** and select **Create Custom Token**.
3. Configure the following properties:
   - **Token name:** `Omada DDNS Sync`
   - **Permissions:** `Zone` -> `DNS` -> `Edit`
   - **Zone Resources:** `Include` -> `Specific zone` -> Select your domain name.
4. Click **Continue to summary**, then click **Create Token**.
5. **Copy the token immediately**—it will only be shown once.

### Step 2: Locate Your Zone ID
1. Navigate to your domain's dashboard overview on Cloudflare.
2. Scroll down to the right sidebar sidebar and copy the alphanumeric string labeled **Zone ID**.

### Step 3: Deploy the Worker & Add Secrets
1. In Cloudflare, go to **Workers & Pages** > **Create Application** > **Create Worker**.
2. Name your worker (e.g., `omada-ddns`) and click **Deploy**.
3. Select **Edit Code** and replace the existing code completely with the `index.js` provided in this repository. Click **Save and Deploy**.
4. Go back to your Worker dashboard, click the **Settings** tab, and navigate to **Variables**.
5. Under **Environment Variables**, click **Add** to input the following three items. Ensure you toggle or select **Encrypt / Secret** for all of them:

| Variable Name (Key) | Value |
| :--- | :--- |
| `OMADA_SECRET_TOKEN` | Create a long, unique, random password string of your choice. |
| `CLOUDFLARE_ZONE_ID` | Paste your Cloudflare Zone ID found in Step 2. |
| `CLOUDFLARE_API_TOKEN` | Paste the API Token generated in Step 1. |

6. Click **Save and Deploy**. Note your worker's live URL (e.g., `https://workers.dev`).

## 2. TP-Link Omada Configuration

Before starting, log into your Cloudflare DNS dashboard and ensure you have manually created an initial **A record** pointing to any arbitrary IP (e.g., `1.1.1.1`) for the domain or subdomain you plan to update.

1. Log into your **Omada Controller** dashboard.
2. Go to **Settings** > **Services** > **Dynamic DNS**.
3. Click **Add New Entry** or **Create New DDNS** and set the configurations as follows:
   - **Service Provider:** Custom
   - **Username:** `not_used` *(Omada requires input, but the script safely ignores this)*
   - **Password:** `not_used` *(Omada requires input, but the script safely ignores this)*
   - **Domain Name:** `yourdomain.com` *(or `://yourdomain.com` depending on your target record)*
   - **Custom URL / Update URL:**
     ```text
     https://workers.dev/?ip=[IP]&domain=[DOMAIN]&u=[USERNAME]&p=[PASSWORD]&secret=YOUR_OMADA_SECRET_TOKEN
     ```
     *(Replace `https://workers.dev/` with your actual live Worker endpoint, and change `YOUR_OMADA_SECRET_TOKEN` to match the exact string you typed into your Cloudflare Environment Variables).*

4. Set your desired **Update Interval** (e.g., 15 minutes) and click **Apply** / **Save**.

### How the URL Syntax Works
Omada dynamically detects the `[IP]` and `[DOMAIN]` flags. When your ISP changes your network's WAN IP address, Omada automatically maps your new public IP and domain string into those parameters, hitting your Cloudflare Worker endpoint to safely execute the DNS update downstream. The Cloudflare worker code will ignore the username and password variables. These are however required by Omada to be sent.
